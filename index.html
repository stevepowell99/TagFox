Settings

Enable Everything HTTP (Tools → Options → HTTP Server). The query updates results live; renames trigger a refresh.

New setup: consider setting one optional search scope folder below (e.g. profile or project drive) so results stay under that tree. The breadcrumb starts there; you can narrow further.

When set, Everything only returns paths under this folder — it is the top of the breadcrumb and the hard ceiling for navigation. Your current folder narrows further inside it (or leave current folder empty to search the whole tree under the scope). Clear for no ceiling (whole index, subject to the breadcrumb).

Re-runs the current Everything query on a timer. Skips while a search is still running, a dialog is open, the tag or rename dialog is busy, or this window is in the background.
