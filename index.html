                Typing letters jumps to matching rows in the results table; this is ignored while the cursor is in a text field.
                Ctrl+/ focuses the search box even from other fields. Many shortcuts are off while a dialog is open, including Ctrl+C,
                X, and V.
              
    
            
    
            
    
              
    
                Current folder is the directory the app searches in and treats as “here”. In Settings, the
                Scope folder field is that path (older wording called it “scope”; it is the same thing).
              
    
              
    Search
    
              
      
                
    • The box under the breadcrumb filters what Everything returns. Results update as you type (debounced). Enter forces a refresh.
      • 
                
    • Clear beside the box only clears the query text.
      • 
                
    • Recursive includes subfolders; off limits to immediate children of the current folder.
      • 
                
    • 
                  Search history (Alt+← / →, or toolbar arrows) steps through past combinations of query, folder, tags, and option toggles.
                  Recent folders (Ctrl+L or the clock button) only jump among saved folder paths, not full search snapshots.
                
      • 
              
    
              
    Breadcrumb
    
              
      
                
    • The path under Favourites is the breadcrumb. Click a segment to set the current folder to that path.
      • 
                
    • 
                  ▾ between segments lists sibling folders on disk; ▾ after the last segment lists subfolders. Hovering opens nested panels to the right;
                  → / ← move between levels in those panels.
                
      • 
              
    
              
    Favourites and recent folders
    
              
      
                
    • Save folder stores the present current folder. Chips recall it; × removes a favourite.
      • 
                
    • The clock menu lists folders you have scoped to recently (same as Ctrl+L).
      • 
              
    
              
    Tags
    
              
      
                
    • Names can carry tags in one bracket block in each segment, e.g. Notes[draft,review].md. Chips in the bar filter the result list (several tags mean all must match).
      • 
              
    
              
    Results, drag, shelf
    
              
      
                
    • Checkboxes on rows drive bulk actions. Drag rows onto a folder row or a breadcrumb segment to move; hold Shift while dropping to copy. The same drag works to Explorer or other apps. The vertical shelf follows the same rules.
      • 
                
    • Column headers sort (sent to Everything). Use the header edges to resize columns.
      • 
              
    
              
    Viewer
    
              
      
                
    • The right-hand Viewer shows details for the highlighted row. With no row selected, it can still show the current folder (e.g. readme.md).
      • 
                
    • It previews common types (PDF, images, Markdown, JSON/text, Office where supported). Very large files may not preview.
      • 
              
    
              
    Row menu (⋯)
    
              
      
                
    • Copy paths, open or reveal on disk, search the cloud by filename, rename, new folder, delete (confirmation), Notepad/Terminal where relevant.
      • 
              
    
              
    Advanced options and toggles
    
              
      
                
    • Settings (toolbar): Everything base URL, Scope folder, max hits, HTTP auth, Sort folders with files.
      • 
                
    • Under the search row: case, whole word, match path, regex, diacritics; Folders only / Files only — off = both types; at most one of these can be on.
      • 
                
    • Hide “dot” folders trims the list of paths that run through segments like .git or .vscode (see the checkbox tooltip—leaf dotfiles such as .env are not hidden).
